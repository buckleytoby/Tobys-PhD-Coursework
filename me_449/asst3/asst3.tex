\section{Part 1 \#7}
{\bf An explanation why convergence is difficult from the long iterates initial guess.}

$\\$

Finding the joint configuration given an end effector configuration is a non-linear process, and is solved numerically via the Newton-Raphson root-finding method. This involves computing locally linearized gradients and then using those gradients to estimate the zero value of the higher order function of interest. 

Since the higher order function is non-linear, the first-order gradient may not be consistent. This may cause erratic gradient values when the input variable is far from a local minima.

\section{Part 2}
a) I'd compute the joint states for the initial transform, and the joint states for the final transform, and then linearly interpolate between the two joint state vectors

\begin{equation}
	\dot{\theta} = (\theta^* - \theta^0) / t_f
\end{equation}


b) I'd compute the unit twist between transforms, scale it to $t_f$, then use that to compute the average joint speed

I'm assuming the FK and IK equations are given.

Forward Kinematics:
\begin{equation}
	T_{sd}(\theta) = FK(\theta^*)
\end{equation}

\begin{equation}
	T_{s0}(\theta) = FK(\theta^0)
\end{equation}

Finding the desired transform
\begin{equation}
	T_{0d}(\theta) = T_{s0}^{-1} \cdot T_{sd}
\end{equation}

Find the desired twist
\begin{equation}
	[\mathcal{V}] = log(T_{0d})
\end{equation}

In the body frame
\begin{equation}
	\mathcal{V} = vec([\mathcal{V}])
\end{equation}

Scale it to $t_f$
\begin{equation}
	\mathcal{V}_d = \mathcal{V} / t_f
\end{equation}


Eq 6.7 in M.R.
\begin{equation}
	\dot \theta^0 = J_B^{\dagger}(\theta^0) \cdot \mathcal{V}_d
\end{equation}

For finding the angular velocity halfway through.

Get the transform halfway through. Left multiply because the desired twist in expressed in the body frame
\begin{equation}
	T_{1/2} = exp([\mathcal{V}_d] * 1/2 * t_f) * T_{0d}
\end{equation}


Do IK to get the joint state halfway through
\begin{equation}
	\theta^{1/2} = IK(T_{1/2})
\end{equation}

Use the Jacobian and the desired twist to get the angular velocities
\begin{equation}
	\dot \theta(t=1/2 \cdot t_f) = J_B^{\dagger}(\theta^{1/2}) \cdot \mathcal{V}_d
\end{equation}

Yes, option A is conceptually easier to understand and implement, and therefore less bug prone. You can also use the current config as given, so only one IK problem must be solved (the goal config).

However, option B ensures the end effector will move in a straight line from the initial config to the goal, meaning that its motion will be predictable in euclidean space. 

This is especially pertinent if there are obstacles and/or objects in the environment that the robot arm wishes to avoid for safety reasons.
